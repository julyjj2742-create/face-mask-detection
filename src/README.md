# src

This project is implemented primarily in a Jupyter notebook:

- `notebooks/Final_Project_FaceMaskDetection.ipynb`

All major steps are handled inside the notebook:
- Dataset loading and preprocessing
- Annotation conversion (Pascal VOC → YOLO)
- Model training with YOLOv8
- Evaluation and metric calculation
- Prediction visualization

(no separate Python scripts were needed for this
implementation because the workflow is fully contained in the notebook)
