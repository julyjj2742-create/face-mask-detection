# About the Dataset

**Dataset Name:** Face Mask Detection  
**Author:** Andrew Mvd  
**Source (Kaggle):** https://www.kaggle.com/datasets/andrewmvd/face-mask-detection


**Contents:**
- 853 images (~7,000 labeled faces)
- Annotation files in Pascal VOC XML format  
- Three classes:
  - `with_mask`
  - `without_mask`
  - `mask_weared_incorrect`

The actual dataset is **not stored in this repository** due to size and licensing restrictions.
All dataset preparation and preprocessing steps are performed in the Jupyter notebook.
