# Trained Models

The model trained for this project (`best.pt` and `last.pt`) is **not included** in the repository
because these files are large and GitHub is not meant for storing model binaries.

You can recreate the trained model by opening the final notebook and running all cells.
YOLOv8 automatically saves:

runs/detect/face_mask_yolov8/weights/best.pt
runs/detect/face_mask_yolov8/weights/last.pt
