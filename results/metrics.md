# Model Evaluation Metrics

The following metrics were obtained from the YOLOv8 `val` command
using the trained face mask detection model:

- **Precision:** 0.934  
- **Recall:** 0.706  
- **mAP50:** 0.823  
- **mAP50-95:** 0.576  

These values show that the model performs well overall, but still has
room for improvement, especially on more difficult cases such as
`mask_weared_incorrect`.
